# chatgpt-hub
Prototype of an AI orchestration hub that acts as a receptionist for multiple AI agents-models. A user prompt enters the HUB, where the system analyzes the request and its context to determine which agent and model are best suited to handle it.

Each agent may have different capabilities, models, tools, or access to specific data, allowing the HUB to route requests to the most appropriate destination rather than relying on a single AI model.

The project is built entirely in Python, with configuration and contextual data stored in JSON.
